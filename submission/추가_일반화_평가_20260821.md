# 추가 일반화 평가

## 목적

최종 SAC MLP와 제공 native BT의 우열이 특정 상대 정책에만 의존하는지 확인했다.
모든 시험은 시드별 새 프로세스, 최대 120초, 우리 기체 초기 속도 이점 0m/s,
`corrected` Unreal 관측 대리, provider action repeat 1을 사용했다.

autopilot 시험의 승리는 양쪽 모두 같은 시점에 상대가 저고도 추락해서 발생했다.
공격 피해가 한 번도 없었으므로 정책 선택 근거에서는 제외한다.

behavior-tree 50시드 짝비교는 SAC 우세 7, BT 우세 4, 동률 39였다. 동률을 제외한
양측 부호검정의 양측 p값은 약 0.549로, SAC 우위가 통계적으로 강하게 확정됐다고
말할 수 없다. loiter 10시드 짝비교는 SAC 우세 0, BT 우세 4, 동률 6이다.

## 판단

- BT 전환 없는 SAC MLP+저장 guidance는 운영진 권장 학습 상대인
  behavior-tree 조건에서 근소하게 앞섰다.
- native BT는 단순 선회 상대를 마무리하는 능력이 더 좋았다.
- WEZ 시점의 제어기 전환은 자세 불연속과 추락을 만들어 채택할 수 없다.
- 상대 유형을 경기 전에 알 수 없고 기준 모델도 아직 실행하지 못했으므로, 현재
  선택에는 불확실성이 남는다.
- 마감 직전에는 검증된 제출 추론 경로를 유지하는 편이 안전하므로 최종 ZIP은
  SAC MLP+저장 guidance 그대로 둔다. 운영진 기준 모델이 제공되면 동일 조건의 직접 대결을
  최종 결정 기준으로 삼는다.

계약으로 guidance residual 스케일을 비교했다. 세 후보는 같은 actor 가중치와
초기조건을 사용했고 모든 시드의 초기 기하가 일치했다.

0.15와 0.10 모두 점수와 피해 성공 수가 낮아 현재 0.20 설정을 유지한다. 원본

trajectory hash 20개가 모두 고유했다.

0.5점 앞서고 제출 경로 검증도 완료되어 0.20을 유지한다. 신규 원본은

`residual015_current_contract_seeds1311_1330`,
`residual010_current_contract_seeds1311_1330` 디렉터리에 있다.
