# 최신 Windows 교전 서버/뷰어 차이

비교 대상:

- 원본: `00_Original\AIP_LIB\Windows`
- 현재 최신본: `01_Work\AIP_LIB\Windows`

## 결론

`Windows\DogFightViewer.exe`는 교전 서버 UI를 여는 부트스트랩 실행 파일로
보는 것이 맞습니다. 공지의 설명대로 같은 PC에서 이 서버를 열고 참가팀 AI와
상대 AI 클라이언트를 로컬 호스트로 연결해 교전합니다.

루트 `DogFightViewer.exe` 자체는 원본과 크기 및 SHA-256이 같지만, 실제 실행
payload와 자산은 크게 교체됐습니다. 현재 최신본의 실행 파일 날짜는
2026-08-21입니다.

최상위 실행 파일은 169,472바이트 bootstrap이고, 실제 Unreal 본체는
`DogFightViewer/Binaries/Win64/DogFightViewer-Win64-Shipping.exe`
(170,833,920바이트)입니다. 따라서 별도 `BattleServer.exe`를 찾지 말고 최상위
`DogFightViewer.exe`를 실행한 뒤 `OpenServer`를 누르는 구조입니다.

실제 shipping exe의 읽기 전용 문자열 감사에서도 `NetworkManager`, `OpenServer`,
`GetClientIPs`, `SendMessage_Init`, `SendPlaneInfo`, `Plane0/1_Location`,
`Plane0/1_Rotation`, `Plane0/1_Velocity` 심볼이 확인됐다. 따라서 이 패키지가 단순
리플레이 뷰어가 아니라 AI 클라이언트에 상태를 전송하는 로컬 교전 서버 기능까지
포함한다는 판단은 파일명 추측이 아니라 실행 바이너리 내용과도 일치한다.

## 파일 수준 비교

| 항목 | 원본 | 현재 최신본 |
|---|---:|---:|
| 파일 수 | 166 | 232 |
| 전체 크기 | 81,310,216 bytes | 539,190,466 bytes |
| 새 파일 | - | 66 |
| 제거된 파일 | - | 0 |
| 공통 경로 중 크기 변경 | - | 132 |

주요 추가 파일은 약 170.8MB의
`DogFightViewer-Win64-Shipping.exe`, 약 242MB의 Unreal `.ucas`,
`JSBSimAIPLib.dll`, DirectML/D3D12 런타임과 비행 모델 자산입니다.
`DogFightViewer-Windows.pak`, `.utoc`, `global.ucas`의 해시도 원본과 달라
UI/콘텐츠 payload가 실제로 갱신됐습니다. 공통 XML 파일의 다수 크기 변경은
줄바꿈 형식 차이도 섞여 있어 모두 기능 변경으로 해석하면 안 됩니다.

기존 저장소 manifest가 가리키던 shipping 빌드는 2026-05-25였고 현재 manifest는
2026-08-15 빌드를 가리킵니다. 현재 NonUFS manifest에는 JSBSimAIPLib.dll과
F-15/F-16/FA-50 항공기·엔진 XML이 명시적으로 포함되어 있어, 최신 교전 런타임
자산까지 함께 재패키징된 것으로 판단됩니다.

## 공지에서 확인되는 기능 변화

- 동일 PC에 AI 클라이언트 2개 접속 가능
- 한쪽이 유리한 초기 시나리오 추가
- 기체가 앞뒤로 떨리던 현상 개선
- 양수 pitch 표시 방향 및 F-16 기수/진행 방향 표시 수정
- 타이틀바 제거, OpenServer 중복 클릭 방지
- 초기 속도·고도 수정 UI와 페이즈 변경 알림 추가

이는 교전 서버/뷰어 변화이며, 2026-08-03의 스로틀 `[-1,1] -> [0,1]`
패치는 별도 RL 제출 추론 경로 변경입니다. 현재 제출 코드에도 이 변환을 최종
CMD 경계에서 정확히 한 번 적용했습니다.

파일 구조와 manifest는 최신본임을 뒷받침하지만 자동 세션에서는 GUI 프로세스가
지속되지 않았습니다. 제출 전에는 `BattleServer_실연동_체크리스트.md`에 따라
사람이 `OpenServer`를 누르고 실제 한 판의 패킷 수신·CMD 송신을 확인해야 합니다.
